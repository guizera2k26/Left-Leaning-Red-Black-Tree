# Left-Leaning-Red-Black-Tree
Este repositório contém uma das três estruturas criadas no  trabalho prático da disciplina Algoritmos e Complexidade Computacional (ACC). A estrutura em questão é a Árvore Rubro-Negra caída para Esquerda, que consiste em uma variante de árvores que usam cores - vermelho e preto - para balanceamento de sua estrutura.
